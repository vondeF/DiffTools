# <img width="30" height="30" alt="DiffTools_icon" src="https://github.com/user-attachments/assets/aa875d30-a8e1-4f7c-b378-c41192b7fa18" /> DiffTools
Утилита для создания наборов изменений между двумя версиями информационной модели (построенных на базе CIM в соответствии с серией ГОСТ Р 58651) и работы с файлами формата CIMXML.

## АИП
### Установка
Утилита поставляется в формате архива, который необходимо распаковать в любое место на локальном ПК.

Работа с утилитой осуществляется по запуску исполняемого файла. Исполняемый файл имеет название **difftools.exe**. Файл конфигурации приложения имеет название **appsettings.json** и разделен на две секции: "Serilog" и "AppSettings". Секция "Serilog" отвечает за настройки логирования.

**Секция "AppSettings" содержит следующие поля:**
1.	**"AssemblyResolvePath"** – путь к папке для загрузки недостающих зависимостей для работы приложения.
2.	**"ModelNavigatorPath"** – путь к исполняемому файлу Редактора модели, необходим для загрузки модулей экспорта.
3.	**"ServerPath"** – наименование сервера АИП.
4.	**"ProvidersDB"** – наименование базы данных, из которой производится загрузка списка модулей экспорта.
5.	**"Databases"** – набор контекстов, доступных для сравнения моделей. При несоответствии наименования БД (поле "Name") с реальным именем контекста необходимо произвести его редактирование. Поле "Description" влияет исключительно на отображение наименование контекста в интерфейсе приложения.

> ⚠ Перед запуском приложения необходимо удостовериться в корректности полей "ServerPath" и "Databases"

> 🚫 Редактирование полей "AssemblyResolvePath", "ModelNavigatorPath", "ProvidersDB" **настоятельно НЕ рекомендуется**

Логи работы приложения расположены в папке **logs**. Файлы логов имеют наименование **Aip_DiffTools_logYYMMDD.log**, где YYMMDD – дата записи логов (YY – год, MM – месяц, DD – день). В папке logs сохраняются 5 последних файлов логов, более старые удаляются.

### Интерфейс
<img width="598" height="853" alt="ИнтерфейсDiffTools испр" src="https://github.com/user-attachments/assets/53550fb3-26f1-4249-b2b7-f2e565797aa2" />

**Элементы интерфейса:**
1.	**«Наименование сервера»** – наименование, записываемое в поле "ServerPath" файла appsettings.json.
2.	**«Наименование контекста»** – набор контекстов, записываемый в поле "Databases" файла appsettings.json.
3.	**«Экспорт по mRID»** – при установке чекбокса выбор модуля экспорта блокируется, формирование набора изменений производится по mRID.
4.	**«Модуль экспорта»** – набор модулей, доступных из редактора модели на ПК пользователя.
5.	**«Сравнить по профилю»** – при установке чекбокса формирование набора изменений производится по профилю, указанному в поле «Путь к файлу профиля».
6.	**«Игнорировать изм. по выбранным классам»** – при установке чекбокса вне зависимости от выбора профиля выше производится игнорирование изменений (кроме добавления и удаления объектов) по классам, указанным в поле «Выбранные классы». Поле «Выбранные классы» редактируемое, при необходимости можно удалить или добавить нужные классы. Наименование класса указывается без префикса cim, rf. So и т.д. При неправильном вводе наименования класса или отсутствии класса в метамодели АИП, будет выведено соответствующее предупреждение при попытке запуска.
7.	**«Модель ДО» и «Модель ПОСЛЕ»** – номер моделей до и после изменений в выбранном контексте.

При нажатии кнопки «Сравнить модель ДО и модель ПОСЛЕ» открывается окно сохранения файла, затем производится формирование набора изменений и запись в xml. 

## САПФИР
### Установка
Утилита расположена по пути **C:\Sapphire DiffTools** на терминальных серверах САПФИР. 
Логи работы приложения расположены в папке **logs**. Файлы логов имеют наименование **Sapphire_DiffTools_logYYMMDD.log**, где YYMMDD – дата записи логов (YY – год, MM – месяц, DD – день). В папке **logs** сохраняются 5 последних файлов логов, более старые удаляются.

### Интерфейс
Интерфейс утилиты разделен на 3 вкладки: Формирование наборов, Подготовка XML файлов, О приложении.
Описание вкладки "Формирование наборов" представлено в разделе АИП - Интерфейс выше.

Вид вкладки "Подготовка XML файлов" представлен ниже.
<img width="595" height="850" alt="ИнтерфейсDiffTools 2 вкладка испр" src="https://github.com/user-attachments/assets/3c086848-1ec4-4220-acad-094ad71311a5" />

**Элементы интерфейса:**
1.	**Область выбранных файлов** – в данной области отображаются выбранные пользователем файлы для редактирования. Загрузка файлов осуществляется кнопкой "Выбрать файлы для обработки". Доступно перемещение файлов (кнопкой со стрелкой вверх), удаление отдельных файлов, а также очистка всей области кнопкой "Очистить список выбранных файлов".
2. **Область функций обработки XML файлов**. Наименование DiffModel/FullModel говорит о применимости данной функции к набору изменений/фрагменту модели.
	- **Заполнение ассоциации cim.Line.SubGeographicalRegion** - дополняет набор изменениями по ассоциации cim.Line.SubGeographicalRegion при наличии изменений по ассоциации cim.SubGeographicalRegion.Line. Сохраняет измененные файлы с пометкой "assocGeo".
	- **Изменение дат** - производит изменения формата дат для раскрытия данных на CIM-портале. Сохраняет измененные файлы с пометкой "dates".
	- **Изменение cim -> so (GOST.xml)** - производит изменения префиксов классов, атрибутов и ассоциаций с cim на so в соотвествии с файлом GOST.xml. Сохраняет измененные файлы с пометкой "prefix".

> ✅ При нажатии любой из кнопок, предназначаенных для обработки файлов CIMXML, открывается окно для выбора папки сохранения результирующих файлов. Исходные файлы не изменяются
